# Hype — нативный iOS-клиент для Hyperliquid

SwiftUI-приложение (iOS 17+) для торговли на Hyperliquid (app.hyperliquid.xyz): перпы и спот, все типы ордеров, портфель, переводы и набор инструментов трейдера.

## Установка (gbox)

1. Откройте вкладку **Actions** репозитория → последний успешный запуск **iOS** → скачайте артефакт `Hype-unsigned-ipa` (внутри `Hype.ipa`).
2. Импортируйте `Hype.ipa` в gbox и подпишите своим сертификатом.
3. Установите и запустите.

IPA собирается без подписи (`CODE_SIGNING_ALLOWED=NO`), bundle id — `com.hype.trader` (gbox может его заменить).

## Подключение аккаунта

**Настройки → Добавить аккаунт.** Типы:

| Тип | Что умеет | Что нужно |
|---|---|---|
| **API-кошелёк** (рекомендуется) | Торговля, плечо, TP/SL, TWAP, отмены | Адрес основного кошелька + приватный ключ API-кошелька с app.hyperliquid.xyz/API |
| **Приватный ключ** | Всё, включая выводы, переводы, Перп⇄Спот, создание API-кошелька | Приватный ключ основного кошелька |
| **Только просмотр** | Позиции, ордера и история любого адреса | Адрес |

API-кошелёк не может выводить средства, поэтому даже при утечке ключа деньги не уйдут с аккаунта. Ключи хранятся в Keychain с доступом `WhenUnlockedThisDeviceOnly`. Можно указать адрес субаккаунта/vault, чтобы торговать от его имени.

## Функции

**Как на сайте**
- Рынки: перпы и спот, поиск, избранное, сортировка по объёму, изменению, фандингу и OI.
- График свечей (1m–1M), зум щипком, прокрутка, перекрестие с OHLC. На графике показаны линии входа, ликвидации, ордеров и алертов.
- Стакан с группировкой (nSigFigs) и глубиной, лента сделок, спред, фандинг с обратным отсчётом, mark/oracle, OI.
- Ордера: рыночный (IOC с проскальзыванием), лимитный (GTC/IOC/Post-only), стоп-маркет, стоп-лимит, тейк-маркет, тейк-лимит, Scale (сетка), TWAP.
- TP/SL вместе с ордером (`normalTpsl`) и на позицию (`positionTpsl`), reduce-only.
- Плечо и режим Cross/Isolated, изменение изолированной маржи.
- Позиции: закрытие по рынку, 25%, 50%, лимитом, разворот. Ордера: изменение (modify) и отмена, «отменить все», «закрыть все».
- Портфель: equity, PnL, маржа, маржин-рейт, график стоимости за 30 дней, спот-балансы, сделки, фандинг, депозиты и переводы, активные TWAP.
- Перевод Перп⇄Спот, вывод в Arbitrum, отправка USDC и спот-токенов (требуется приватный ключ).
- Mainnet и Testnet.

**Дополнительно**
- Риск-сайзинг: размер позиции считается из риска в $ или % депозита и стоп-лосса. Кнопки быстрого TP/SL с соотношением 1:2.
- Предпросмотр ордера: стоимость, маржа, оценка ликвидации, комиссия по вашему тиру, PnL по TP и SL. Перед отправкой показывается экран подтверждения.
- Ценовые алерты с локальными уведомлениями: в реальном времени и в фоне через BGAppRefresh.
- Сканер фандинга (APR), лидеры роста и падения.
- Калькуляторы: размер по риску, PnL/ROE с комиссиями, цена ликвидации.
- Авто-отмена ордеров (dead man's switch, `scheduleCancel`).
- Несколько аккаунтов с быстрым переключением, режим наблюдения.
- Блокировка Face ID, вибрация, уведомления об исполнении.
- Создание API-кошелька прямо из приложения (`approveAgent`).

## Архитектура

```
HyperCore/            Swift Package: подпись и сериализация (без UI)
  Keccak, MsgPack (байт-в-байт с Python msgpack), EIP-712,
  HLSigning (action hash → phantom agent / user-signed), HLActions, HLNumber
  secp256k1 — libsecp256k1 через swift-secp256k1 0.24.0
  Tests/ — сверка подписей с официальным hyperliquid-python-sdk
App/
  Core/   AppModel (состояние, REST + WebSocket), Trading, Network, Socket, Models
  Views/  Markets, Trade (график, стакан, форма ордера), Portfolio, Tools, Settings
project.yml           XcodeGen
tools/gen_vectors.py  генерация тестовых векторов
```

## Сборка локально (macOS)

```bash
brew install xcodegen
xcodegen generate
open Hype.xcodeproj
cd HyperCore && swift test   # тесты подписи
```

## Отказ от ответственности

Неофициальный клиент. Торговля с плечом связана с высоким риском. Перед торговлей на mainnet проверьте приложение на testnet.
